# Requisitos de referencia

La fuente de requisitos es `PLAN.md`. Este documento no agrega reglas comerciales.

Para la estructura inicial se respetan estos límites:

- Aplicación de escritorio Windows, para una única PC y operación local/offline.
- Arquitectura C# + WPF + SQLite candidata, sin API HTTP, microservicios ni contenedores.
- Separación entre interfaz, aplicación, dominio e infraestructura.
- Base SQLite futura fuera del instalador, `Program Files` y el repositorio.
- No se implementan ventas, inventario, caja, cambios, clientes, cuentas corrientes ni facturación en F00-T01.

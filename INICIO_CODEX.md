# Primera instrucción para Codex

Copiar y pegar este texto al abrir la carpeta del proyecto en Codex:

```text
Leé PLAN.md y ESTRUCTURA.md completos. Ejecutá solamente F00-T01. Antes de crear archivos, proponé el árbol mínimo que vas a materializar y comprobá si ya existe alguno. Conservá la estructura objetivo de ESTRUCTURA.md, pero no crees carpetas vacías ni pantallas de módulos futuros. No inventes una versión definitiva de .NET, reglas de fiado, facturación ni permisos. Si necesitás fijar un framework provisional para que el esqueleto compile, dejalo anotado para validar en F00-T02. Creá el .gitignore, README, solución y proyectos estrictamente necesarios para ese primer hito. Compilá si el entorno lo permite e informá el resultado real; si no, dejá el comando para ejecutarlo en Windows sin afirmar que compiló. Actualizá el estado del plan únicamente si verificaste la tarea. No continúes a F00-T02 sin mi indicación.
```
